# Egern 个人分流规则

本仓库用于存放个人维护的 Egern 分流规则，所有可订阅的规则文件统一放在 `Egern` 文件夹中。

## 规则文件

| 文件 | 对应服务 |
| --- | --- |
| `1Password.list` | 1Password |
| `Bitwarden.list` | Bitwarden |
| `Grok.list` | Grok 与 xAI |
| `Manus.list` | Manus |
| `MastercardCN.list` | 万事达卡中国 |
| `Perplexity.list` | Perplexity |
| `Raindrop.list` | Raindrop.io |

## 订阅地址

规则文件的原始地址格式如下：

```text
https://raw.githubusercontent.com/hbchnz/Rules/main/Egern/文件名
```

例如，Grok 规则的订阅地址为：

```text
https://raw.githubusercontent.com/hbchnz/Rules/main/Egern/Grok.list
```

移动文件后，仓库根目录下原有的订阅地址将不再有效，请在 Egern 配置中使用包含 `/Egern/` 的新地址。
